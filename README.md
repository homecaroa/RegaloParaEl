# Acierto · Tienda de packs de regalo para hombres

Tienda estática (HTML/CSS/JS modular, sin compilación). Nombre de marca **provisional**.

## Ejecutar en local
python3 -m http.server 8000  → abrir http://localhost:8000

(No abrir index.html con doble clic: los módulos ES no cargan desde file://.)

## Dónde se edita cada cosa
- Packs, precios y artículos: `src/data/products.js`
- Marca, empresa, envío y supuestos económicos: `src/data/site.config.js`

## Estado
Ver `docs/ESTADO.md`. Todo contenido es provisional hasta verificar productos, proveedores, precios y textos legales.
